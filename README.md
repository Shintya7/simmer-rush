Simmer Rush is an original 2D canvas cooking game: you are the only chef in a tiny kitchen on a three-minute dinner rush. Order tickets land on the board with a countdown, and you run the route — grab ingredients from the counter, hold to chop at the board, cook patties on the stove before they burn, stack the dish on the plate, and carry it to the serving window before the ticket runs out. Fast serves earn tips, serves in a row build a combo, and the menu grows longer and the tickets arrive faster as the shift wears on. Keyboard (WASD/arrows + E) and mouse (click-to-move) both work, sounds are generated live with WebAudio, and everything is drawn in canvas 2D with no network requests. Six original dishes, one chef, one very busy pass.

## Run it

```sh
node main.ts
```
